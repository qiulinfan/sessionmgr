# Session Manager v1.4.4 Devlog

> Status: Development
> Date: 2026-10-13

## Objective and scope

Back up Codex sidebar roots and Claude Desktop-origin roots together, while excluding CLI/SDK jobs, subagents and OpenCode from this scoped workflow.

## Work completed

- Add `export --desktop-only` with explicit `scope=codex-claude-desktop` and a separate incremental checkpoint.
- Preserve `--sidebar-only` as the existing Codex-only interface and unrestricted source selections when neither flag is set.
- Filter Claude before parsing: only the physical file ID's own `claude-desktop` records establish membership; copied ancestry, sidechain, agent IDs, cloud, unknown and CLI/SDK entrypoints cannot.
- Use the combined scope for the Web UI's default conversation-only checkbox.
- Private sync-sessions consumer independently verifies harness-specific native IDs before staging. Scheduled Diary candidate selection uses the same allowlists.

## Decisions and rationale

Codex has a native active-sidebar inventory. Claude's local transcripts expose Desktop origin but no verified current-sidebar/archive registry. The new name states the actual guarantee instead of claiming identical sidebar semantics. OpenCode is not selected.

## Compatibility and migration

Export JSON remains schema 6; the new flag adds a new explicit scope. Metadata and renderer schemas are unchanged. Optional `DesktopOnly` contributes to checkpoint identity only when enabled, preserving previous scopes. First combined export discovers older eligible Claude sources; modified documents and old hashes remain protected.

## Known limitations and risks

- Desktop provenance is not proof of current Claude sidebar membership or archive status.
- Claude origins without explicit Desktop markers fail closed. Malformed transcripts are excluded from identity selection until valid.
- This is a local development build, not a published release; GUI visual operation is not verified.
