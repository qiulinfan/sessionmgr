# Session Manager Devlogs

Devlogs are the durable engineering handoff for each product version. They
record what changed, why it changed, what was actually verified, and what the
next developer or Agent still needs to investigate.

The repository-level requirements are defined in
[`AGENTS.md`](../../AGENTS.md). Start new logs from
[`TEMPLATE.md`](./TEMPLATE.md).
