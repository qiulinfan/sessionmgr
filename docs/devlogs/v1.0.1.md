# Session Manager v1.0.1 Devlog

> Status: Released
> Date: 2026-08-20

## Objective and scope

Fix the Windows release builder so the reviewed 1.0 product can be published on
GitHub-hosted Windows runners whose `PATH` exposes more than one Go application.
This patch release does not change session discovery, parsing, rendering,
identity, archive schemas, GUI behavior, or CLI behavior.

## Work completed

### Release builder

- Changed `scripts/build-windows-release.ps1` to select the first
  `Get-Command go -CommandType Application` result, preserving normal PATH
  precedence while ensuring `$goExecutable` is one path rather than an array.
- Advanced the source version from `1.0.0` to `1.0.1` for a fix-forward release.

### Failed immutable release evidence

- The immutable `v1.0.0` tag correctly passed source validation, dependency
  verification, vet, tests, and race tests.
- GitHub Windows job `96407835358` failed before asset generation because the
  runner exposed Go 1.26.5 and Go 1.24.13; PowerShell expanded both `.Source`
  values into one command string.
- No v1.0.0 assets were staged and the publish job was skipped. The tag was not
  deleted, moved, or reused.

## Decisions and rationale

- **Fix forward to 1.0.1:** published tags and Released devlogs are immutable;
  correcting the builder under a new patch version keeps release provenance
  honest.
- **Honor PATH precedence:** choosing the first application matches ordinary
  command resolution and the Go version installed earlier by `actions/setup-go`.
- **Keep the fix minimal:** the resource tool, linker flags, PE checks, version
  execution, icon extraction, and artifact contract remain unchanged.

  prove the hosted-runner environment is fixed.
- Windows binaries remain unsigned and may trigger SmartScreen.
