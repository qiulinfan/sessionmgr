# Session Manager v1.5.0 Devlog

> Status: Development
> Date: 2026-10-15

## Objective and scope

A shared, optional GUI-only export setting for CLI and Web UI, including verified OpenCode Desktop list membership. Default off preserves CLI users' broad export behavior.

## Work completed

- Persist `gui_only` in config schema 4. `smg config set-gui-only true|false`, config inspection, and the Web UI toggle share it. A one-time `export --gui-only=false` does not change the saved preference.
- Add `export --gui-only` with JSON scope `gui-conversations`. Source checkboxes remain authoritative; unsupported GUI identities (DeepSeek/OMP) are excluded in this scope.
- Codex uses its native active Desktop inventory; Claude uses explicit Desktop-origin root transcripts. Existing `--sidebar-only` and `--desktop-only` retain their former semantics.
- OpenCode matches its Desktop local project registry, exact directory, no parent, and no archive time. Unknown/missing state fails closed. Expose `--opencode-gui-home` for custom state paths. Never infer membership from titles or closed-tab history.
- Update the private backup consumer and its second independent identity gate to include OpenCode GUI-list roots. The daily schedule uses explicit GUI scope independent of global preferences.

## Decisions and rationale

The owner accepts GUI-list membership, regardless of original creation entrypoint. Read-only inspection of installed OpenCode Desktop 1.18.34 renderer confirmed `isRootVisibleSession` and `server.projects.local`; local UI showed the project list. In this scope a CLI-created root in a GUI-listed project can be eligible. This is deliberately not a claim about GUI creation origin. Desktop state is never modified.

## Compatibility and migration

Config schema 4 reads schemas 1–3; old settings remain GUI-only=false and source selections survive. Older binaries cannot read schema 4; retain the new installed binary. Export JSON remains schema 6, adding a named scope. Checkpoints include the new scope and GUI state path; broad and legacy scope keys remain unchanged. Native sessions and archived Markdown/hashes are untouched.

## Known limitations and risks

- Claude Desktop provenance is not a verified active-sidebar/archive registry.
- OpenCode state format is version-specific and fail-closed on unknown shape. Only local server projects are selected; remote servers require separate verified capture.
- Missing selected GUI inventories block this scope; deselect a harness not installed on the machine.
- Closed-tab history is not an inventory. Existing engine temporary-job exclusions still apply.
- This version is not a published GitHub release.
