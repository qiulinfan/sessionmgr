# Session Manager v1.4.1 Devlog

> Status: Released
> Date: 2026-09-30

## Objective and scope

Finish the custom-path command surface introduced in v1.4.0 by making
`smg search --repo .` and `--repo ..` resolve Git repository identity. Retain
the scoped metadata/search/show behavior, export policy and existing formats.

## Work completed

- Recognize exact `.` and `..` values as checkout paths, alongside existing
  absolute, `./`, `../` and literal home-relative paths.
- Added a real local Git fixture regression covering current, parent, relative
  child and absolute checkout arguments, including invocation from a nested
  folder. Query configuration remains byte-for-byte unchanged.
- Updated the source version, command specification and release notes.

## Decisions and rationale

- Preserve the v1.4.0 tag and its devlog. The final CLI check found this path
  bug after tagging; its release workflow was cancelled before publication.
- Resolve checkout identity using the existing repository helper. Keep names,
  hosted remotes and repository keys as their existing selectors.

## Compatibility and migration

- No persisted schema, archive layout or existing JSON format changes.
- `search --repo .` / `..` now select the intended checkout rather than literal
  repository names. Existing explicit name/remote/key selection is preserved.
- All other v1.4.0 retrieval and path semantics remain unchanged.

## Known limitations and risks

- This patch does not repair modified archive hashes or normalize Markdown.
- Platform runtime/signing limits remain as recorded in v1.3.0 and v1.4.0.
