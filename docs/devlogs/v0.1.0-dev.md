# Session Manager v0.1.0-dev Devlog

> Status: Development MVP
> Date: 2026-07-30

## Objective and scope

Build the first runnable Session Manager CLI that can bind a Codex session to
its exact Git worksite, archive both as an immutable Run, move that Run through
a user-owned Store, restore it in a new worktree, and provide a truthful
handoff when native session resume is unavailable.

This version targets macOS and Linux, one primary Git workspace per Run, the
Codex adapter, local directory Stores, and SSH-backed encrypted transfer.

## Work completed

### CLI and local state

- Added the `sessionmgr` CLI with `init`, `doctor`, `capture`, `list`, `show`,
  `verify`, `restore`, `handoff`, `push`, `pull`, and `reconcile` commands.
- Added human-readable and structured JSON results with stable operation
  reports.
- Added `SESSIONMGR_HOME`, machine identity, restrictive filesystem
  permissions, TOML configuration, and an age identity generated by `init`.
- Added a rebuildable pure-Go SQLite catalog for Run, repository, machine,
  Agent, lineage, path mapping, and sync metadata.

### Git workspace capture and restore

- Captures repository identity, branch, HEAD, upstream, Git capabilities, and
  merge/rebase/cherry-pick state.
- Preserves otherwise unavailable commits in a Git bundle.
- Stores staged and unstaged binary patches separately.
- Stores non-ignored untracked files and explicitly selected ignored files as
  content-addressed objects, including executable mode and safe symlinks.
- Restores in the required order: commits, staged patch, unstaged patch, and
  untracked files.
- Defaults to a new `sessionmgr/restore/<run>` branch and an isolated worktree.
- Recomputes the workspace digest after restore and fails on any mismatch.
- Rejects unsafe paths, `.git` collisions, case-folding collisions, escaping
  symlinks, non-empty targets, and existing untracked files.

### Codex adapter and handoff

- Discovers Codex JSONL sessions by canonical workspace path or native ID.
- Copies raw JSONL byte-for-byte after checking that the source file stayed
  stable during capture.
- Produces a versioned normalized event stream while preserving unknown records
  exclusively in the raw object.
- Excludes Codex authentication, SQLite, WAL, logs, shell snapshots, and device
  state from capture.
- Implements experimental native JSONL import with native-ID collision
  protection.
- Generates deterministic Markdown handoffs from Git facts and normalized
  evidence without claiming that unobserved tests passed.

### Capsule, Store, encryption, and safety

- Added canonical JSON manifests, SHA-256 object descriptors, immutable Run
  refs, atomic local publication, and deep offline verification.
- Added deterministic tar and zstd encoding wrapped in randomized age
  encryption for SSH transfer.
- Added path-safe, size-bounded streaming Capsule import.
- Added local directory Store set-union push/pull.
- Added SSH upload through temporary names, ciphertext checksum verification,
  and last-step atomic Run ref publication.
- Caches encrypted Capsules by manifest and recipient set so interrupted SSH
  publication can reuse the same ciphertext.
- Added secret scanning for private keys, high-confidence provider tokens,
  credential-bearing remotes, suspicious environment assignments, patches,
  untracked content, raw sessions, and handoff inputs.
- Remote SSH push is blocked when the Run contains blocking security findings.

### Project structure and documentation

- Added manifest and normalized-event JSON schemas.
- Added a no-CGO Makefile build and repository `.gitignore`.
- Updated the README with build, command, Store, encryption, and capability
  documentation.
- Added repository development rules requiring one evidence-based devlog for
  every version.

## Decisions and rationale

- **Go and no CGO:** the product is intended to ship as a portable single
  binary, so the catalog uses `modernc.org/sqlite` rather than a C-backed
  SQLite driver.
- **Raw-first adapter model:** normalized events are useful for search and
  handoff, but private Agent formats evolve. Raw JSONL remains the archival
  source of truth.
- **Immutable content-addressed storage:** payload objects and Run refs avoid
  last-write-wins behavior and make interrupted publication recoverable.
- **Restore into a new worktree:** isolation prevents accidental mutation of a
  dirty user workspace and leaves failed restores available for diagnosis.
- **Capability honesty:** Codex does not expose a stable import contract, so
  native restore remains experimental and handoff is always the safe fallback.
- **Stream encryption outside compression:** Capsule encoding follows
  deterministic tar, then zstd, then randomized age encryption. Remote storage
  does not receive plaintext object digests or key material.

## Compatibility and migration

- Introduces manifest schema version `1`.
- Introduces normalized event schema version `1`.
- Introduces config schema version `1`.
- Introduces the `.smcap.age` encrypted Capsule transport representation.
- There is no older implemented Session Manager format to migrate.
- Unknown optional normalized records remain available in raw session objects.
  Unknown required object media types or capabilities are intended to block
  restore.

## Known limitations and risks

- Codex native restore is experimental. The adapter does not yet have a
  verified compatibility matrix across Codex App and CLI versions.
- Native restore does not yet merge every Codex title/archive index variant.
- The SSH path is implemented and its parsing, caching, encryption, and local
  round trips are tested, but a real remote SSH handshake and server filesystem
  matrix has not been exercised.
- The deterministic handoff is deliberately conservative. Codex record
  variants that cannot prove a verification result will produce “no structured
  verification evidence” instead of an inferred pass.
- `reconcile` verifies the local identity but does not yet expose a full
  quarantine browser or choose between conflicting manifests.
- Run lineage fields exist, but user-facing revision and fork commands are not
  implemented yet.
- Capture reports submodule, Git LFS, shallow clone, partial clone, and sparse
  checkout capability warnings; it does not guarantee full external object
  recovery for those repository modes.
- Windows and WSL are outside this version's supported platform matrix.

   restore, and same-Store push.
4. Add quarantine inspection and explicit resolution for same-Run manifest
   conflicts.
5. Improve structured verification extraction while retaining secret-safe tool
   summaries and evidence references.
6. Add revision/fork CLI operations and lineage-focused catalog tests.
